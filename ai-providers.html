AI Providers & Prompts

A multi-provider connection router turns plain-text prompts into calibrated placement profiles. Configure it under Tools → ByteLura → AI Settings Manager.

Providers

  • Local Offline Parser — free, works instantly using keyword heuristics; no account, no connection.
  • Google Gemini
  • OpenAI — the GPT-4o model suite.
  • Claude — Anthropic Claude 3.5 Sonnet.
  • Grok — xAI API integration.
  • OpenRouter — unified aggregator API.
  • Ollama — local open-source models such as Llama 3 and Mistral running on your own PC.

Select your preferred provider in the left panel of the AI Settings Manager.

Setting up cloud providers

  1. Enter your API key in the password-masked field (use the reveal button to verify it).
  2. The link icon shortcut opens the provider's developer console, where you obtain a key.
  3. Click Test Connection — the tool performs a non-blocking test request. A green banner shows latency in milliseconds on success; a red banner shows the exact API error on failure.

Setting up Ollama (fully local)

  1. Make sure your local Ollama server is running — by default at http://localhost:11434.
  2. Enter the base URL endpoint in the settings.
  3. Select the desired model, or check Use Custom Model to type a model tag manually.

With Ollama, generation runs entirely on your local GPU: no API fees and no project data leaves your machine.

Key security

All API keys and credentials are saved locally on your machine using Unity's EditorPrefs. They are never stored in files or scriptable assets and never committed to version control.

How prompts become placements

The active provider interprets your description and computes the scatter constraints for the profile — slope thresholds, height limits, normal alignment and density ratios. Requests are processed asynchronously through an event-driven loop hooked into the editor's update cycle, so the Unity editor does not freeze while waiting for a response. The same prompt pipeline drives the Storytelling module and the Layout Builder.

Performance & Mesh Combiner

Thousands of individual GameObjects cost draw calls. Two systems keep scattered scenes fast: the performance budget, which limits how much you scatter, and the static mesh combiner, which merges what you scattered.

Performance budget system

Located in the Performance tab of the main window. Each tier clamps your profile's scatter parameters to a hardware target:

Apply Budget scales and clamps profile density and spacing so the environment meets the chosen target, and warns you when LODs (Level of Detail) are recommended.

Static Mesh Combiner

Open it at Tools → ByteLura → Static Mesh Combiner. It merges separate scattered GameObjects that share the same materials into single optimized static meshes, cutting draw calls to a fraction.

How to use

  1. Assign the target parent object (for example a [Scatter] group) containing the scattered child props.
  2. Toggle Deactivate Original Child Objects to disable the children while preserving them for future tweaking.
  3. Toggle Generate Combined Mesh Colliders to create optimized physics colliders.
  4. Toggle Save Combined Mesh as Project Asset to save meshes as .asset files inside the project, so they load correctly in standalone builds.
  5. Select a save folder and click COMBINE & OPTIMIZE MESHES.

Technical details

  • Submeshes are grouped by material, with automatic secondary lightmap UV generation for baked global illumination.
  • A 32-bit index buffer (IndexFormat.UInt32) lets meshes with more than 65,535 vertices combine into a single mesh group per material without overflow.
  • Restore Originals reverts to the editable prefabs at any time, and all changes support Undo.

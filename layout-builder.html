Layout Builder

The AI Modular Layout Builder (Tools → ByteLura → AI Modular Layout Builder) is a native 3D layout solver that constructs connected room structures in the editor from a text description.

How it works

  1. Text prompt — describe your map, for example: "A medieval dungeon with a torture room, an armory, a loot vault, and a dragon boss chamber".
  2. Graph generation — the active AI provider returns a structured room connection graph: room ids, types (spawn, battle, loot, boss, corridor), dimensions (width, length, height) and connection pathways.
  3. Layout solver — a local C# BFS AABB layout solver calculates non-overlapping 3D coordinates for all rooms so they align and connect accurately.
  4. Shell generation — modular floors, ceilings and walls are instantiated.
  5. Doorway carving — doorways are carved through overlapping walls where rooms connect, with decorative wood or metal doorframes.
  6. Accent lighting — an ambient directional light (theme-colored sun) plus localized point lights inside each room: cyan/blue for Sci-Fi, red/purple for Horror, warm yellow/orange for Medieval and Industrial.
  7. Prop scattering — props from the active profile (or demo assets) are raycast-scattered inside each room according to its type: more clutter in loot rooms, boss props in boss chambers, clear pathways in corridors.

Configuration

  • Theme Override — force a visual style: Sci-Fi, Medieval, Horror or Industrial.
  • Wall Thickness — 0.1 m to 1.0 m.
  • Doorway Width & Height — the size of carved openings.
  • Prop Profile — the Scatter Profile that determines what is scattered inside the rooms.
  • Auto-clean [AI Layout] parent — when checked, regenerating deletes the previously spawned layout group first.

Level summary

After generation, a summary panel lists the theme, the total rooms placed and per-room statistics. Clear Generated Layout Objects removes the spawned elements at any time, and every operation is integrated with Unity's Undo history.

Connection requirement: the layout builder queries the AI provider for the room graph, so it requires a cloud provider such as Gemini or OpenAI. It does not run on the Local Offline Parser — see Honest Limits.

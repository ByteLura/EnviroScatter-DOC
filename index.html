EnviroScatter Pro AI

An editor-only environment generation and scatter suite for Unity. Describe a world in plain language or place props with rule-based scattering, and EnviroScatter Pro AI turns a blank terrain or mesh into a dressed, production-ready scene.

What it does

  • Multi-surface scattering — props are placed by raycast across Unity Terrains and custom 3D Mesh Colliders, with slope, height, spacing and collision rules, and a live preview before anything is committed.
  • Natural-language AI configuration — type a description such as "A dense Nordic pine forest on damp terrain with mossy boulders" and the active AI provider computes calibrated scatter constraints (slope thresholds, height limits, normal alignment, density ratios) for your profile.
  • Direct placement tools — an interactive SceneView paint brush and a spline-based road and path decorator for hands-on dressing.
  • Scene auditing — a 32x32 density heatmap, an art-style consistency analyzer and a composition assistant show hotspots, dead zones and style clashes before you export a build.
  • Optimization — platform performance budgets clamp scatter density per hardware tier, and the static mesh combiner merges scattered props into single draw calls with lightmap UVs.
  • Modular layout building — generate connected multi-room layouts (spawn, battle, loot, boss, corridor) from a text description.

Who it is for

  • Level designers — turn blank terrains into rich, story-driven worlds in minutes instead of days.
  • Technical artists — hold strict draw-call budgets with the static mesh combiner and five-tier platform budget scaling.
  • Solo indie developers — build dense, high-quality environments without a dedicated environment art team.
  • Producers and leads — reduce level authoring time while keeping a consistent visual style across team members.

Honest scope

EnviroScatter Pro AI is an editor tool. All of its code lives in an editor assembly, so nothing from the package runs in your exported player builds. Cloud AI providers are optional: a built-in offline keyword parser and a local Ollama connection let you work without any cloud account, with one exception — the modular layout builder needs a cloud provider (see Honest Limits). The full, unvarnished list of boundaries is on the Honest Limits page.

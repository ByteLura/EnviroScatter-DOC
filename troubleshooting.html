Troubleshooting & FAQ

I click "Generate Preview" but nothing is placed or previewed

Usually one of the following:

  1. Selection bounds — make sure the green bounding box is aligned directly over your target mesh or terrain. Select the object in the Hierarchy and click Fit Bounds to Selection.
  2. Raycast misses — the surface must have a Collider component (for example a MeshCollider) so the top-down placement raycasts can find it. The tool automatically adds one to mesh renderers if missing, but check to be sure.
  3. Height filters — if the Height Filter toggle is enabled, verify your minHeight and maxHeight limits contain the surface's Y coordinates.
  4. Spacing conflicts — if Min Spacing is too high relative to your bounds size, new candidates are rejected. Lower Min Spacing.
  5. Boundary padding — padding wider than the selection bounds clamps placement to a zero area. The tool clamps padding to 40% of the bounds size to prevent this.

The editor generated a huge number of light sources while scattering

This was a bug in previous versions, where global components (Directional Lights, Cameras, AudioListeners) could be scattered. The engine now audits the prefabs in your profile: if it detects a Directional Light, Camera or AudioListener inside any assigned prefab, it blocks generation and shows a warning message.

The AI settings connection test fails

  1. Cloud APIs — make sure you entered a valid API key, that you have internet access, and that your firewall is not blocking connections.
  2. Ollama (local) — make sure your local Ollama application is running (by default on http://localhost:11434). Try opening it in a browser first.
  3. Endpoint URL — aggregators such as OpenRouter, and local proxies, require the correct endpoint URL structure. Refer to the AI Settings Manager for the defaults.

The AI layout generator fails to build rooms

The layout builder requires a cloud connection to query the language model for the room graph. If you are using the Local Offline Parser in settings, switch to a cloud provider such as Gemini or OpenAI. See the Layout Builder page.

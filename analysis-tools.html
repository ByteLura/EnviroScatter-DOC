Analysis Tools

Three tools audit the visual quality of a scene: style harmony, composition, and context-aware placement.

AI Style Consistency Analyzer

Open it at Tools → ByteLura → AI Style Consistency Analyzer. It scans materials, meshes and textures in the current scene to detect style mismatches.

  • Scene scanning — calculates the dominant style: Medieval, SciFi, Horror, Realistic, Stylized, Industrial or Fantasy.
  • Profile audit — scans the active Scatter Profile's prefabs and warns if any assigned asset breaks the visual theme (for example, a Sci-Fi computer terminal in a Medieval dungeon).
  • Style badges — the detected style is displayed with color-coded badges, warnings and advice.

AI Composition Assistant

Open it at Tools → ByteLura → AI Composition Assistant. It analyzes the layout balance and height distribution of placed objects.

  • Quadrant balance check — divides the scene bounds into 4 quadrants, counts scattered objects in each, draws a 2x2 grid preview and calculates a 0-100% balance score.
  • Silhouette check — calculates vertical height variety using Shannon-entropy math and draws a height-distribution bar chart. A low variety score flags that too many objects share the same height.
  • Focal point — calculates the exact spatial centroid of all scattered items and renders it as a 3D target cross-hair gizmo in the SceneView.
  • Copy Report — exports the full layout analysis to the clipboard.

Semantic Scatter Filter

Open it at Tools → ByteLura → Semantic Scatter Filter. It enables context-aware placement using physics overlap checks.

  • Tags — surrounding geometry is classified as NearWall, NearRoad, NearCorner, OpenField, Elevated or NearWater.
  • Scan Scene Origin — place the SceneView camera anywhere and scan to inspect the local semantic context tags.
  • Saved rules — semantic filtering conditions are saved to EditorPrefs. When enabled, the core engine automatically filters candidates by these rules (for example, grass only in Open Fields, mushrooms only Near Walls).

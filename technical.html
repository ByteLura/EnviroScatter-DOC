Compatibility & Technical Details

Supported Unity versions

  • Unity 2021.3 LTS (verified)
  • Unity 2022.3 LTS (recommended)
  • Unity 2023.x (verified)
  • Unity 6 (6000.x) and newer (fully supported)

Render pipelines

  • Universal Render Pipeline (URP) — all versions
  • High Definition Render Pipeline (HDRP) — all versions
  • Built-in Render Pipeline — Forward and Deferred

Platforms

  • Authoring OS: Windows 10/11, macOS (Intel and Apple Silicon), Linux.
  • Target export platforms: Standalone PC / Mac / Linux, Android, iOS, PlayStation 5, Xbox Series X/S, Nintendo Switch, WebGL, Meta Quest (VR/AR).

Package architecture

  • Editor-only: all code is isolated inside the ByteLura.EnviroScatter.Editor assembly. No scripts or CPU/memory overhead from this package are included in your exported player builds.
  • Zero external dependencies: the toolchain is self-contained and requires no third-party plugins.
  • Namespaces: ByteLura.EnviroScatter.Editor, with .Sampling, .Rules and .Profiles sub-namespaces.
  • Profiles are ScriptableObject assets — a clean architecture that causes no version-control bloat.
  • API keys are stored in EditorPrefs on your machine only (see AI Providers & Prompts).

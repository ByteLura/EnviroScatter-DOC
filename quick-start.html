Quick Start

From import to your first scattered environment in five steps. Package path in your project: Assets/ByteLura/EnviroScatter Pro AI.

Step 1 — Create the demo scene (recommended)

  1. Open the Unity menu: Tools → ByteLura → Setup Demo Scene.
  2. A dialog confirms creation of a pre-populated scene.
  3. The demo scene contains a ground plane, scattered items and a floating visual guide, so you can see the full loop running immediately.

Step 2 — Manual setup in your own scene

  1. Create a terrain or a mesh surface (for example a Plane or another 3D GameObject) in your scene.
  2. Make sure the object has a Collider component (TerrainCollider or MeshCollider) — placement raycasts need one.
  3. Select the object in the Hierarchy.

Step 3 — Open the main window

  1. Open Tools → ByteLura → EnviroScatter Pro AI and dock the window in your editor layout.
  2. Click Use Selected next to the Target Surface field, or drag your ground object into the field.
  3. Click Fit Bounds to Selection to align the green boundary box over the ground.

Step 4 — Create a Scatter Profile

All placement rules (densities, spacing, slope limits) and prefab lists live in a Scatter Profile asset.

  1. In the main window, click Create New Profile and save it under your project's Assets folder.
  2. If the profile is empty, the editor automatically populates it with procedural tree, rock and grass demo prefabs so you can test immediately.

Step 5 — Generate and apply

  1. Under the Scatter tab, click Generate Preview. Green circles mark accepted spots and red crosses mark rejected spots in the SceneView.
  2. Adjust the sliders (Density, Min Spacing, Max Slope) and watch the preview update.
  3. Click Apply Placement to instantiate the prefabs into the Hierarchy.
  4. Spawned prefabs are grouped under a [Scatter] parent object and fully support Ctrl+Z undo.
